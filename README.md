# Min Ekonomi v0.5.1

Installerbar PWA för GitHub Pages-adressen `https://lassemicke-wq.github.io/Min-Budget/`.

1. Radera gamla appfiler i repositoryts rot, men inte repositoryt.
2. Ladda upp alla filer från zip-paketet direkt i roten.
3. Vänta på grön GitHub Pages-deploy under Actions.
4. Öppna adressen på mobilen och kontrollera att rubriken visar version 0.5.1.
5. I Chrome: tre punkter > Lägg till på startskärmen > Installera.

Data ligger i IndexedDB och backup exporteras som JSON.
