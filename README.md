# Min Ekonomi PWA v0.4

Fristående privatekonomi-PWA. Data lagras lokalt i IndexedDB. Ingen OneDrive- eller arbetskontokoppling krävs.

## Säkerhetskopiering
Inställningar visar senaste export, antal poster/kategorier och budgetår. Export skapar en fullständig JSON-backup med metadata. Import granskar filen och visar innehållet innan återställning. Återställning ersätter befintlig appdata.

## Rekommenderad rutin
Exportera efter större registreringsomgångar och minst en gång per månad. Förvara gärna två kopior på platser som inte är arbetsgivarberoende.
