# Min Ekonomi v0.14.0 Budget Recurring

Budgetplanen kan nu skapa och hantera återkommande utgifter direkt på varje kategori. Kryssa i Återkommande, fyll belopp, dag, startdatum och Auto På/Av, och spara. Befintlig återkommande mall visas på budgetraden. Avmarkering tar bort mallen men behåller historiska poster. Om budgetbeloppet ändras erbjuds synkning till mallen. Avancerad redigering finns kvar under Återkommande.

Svensk helgdagslogik, automatisk generering, dublettskydd, tema och tidigare funktioner är kvar. Samma IndexedDB används.
